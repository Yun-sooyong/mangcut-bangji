# 망컷방지

구도 가이드와 빈티지 필터를 제공하는 카메라 앱입니다.

사용자는 촬영 장면을 고릅니다. 앱은 그 장면에 맞는 구도 가이드를 카메라 화면 위에 표시합니다. 사용자는 가이드에 맞춰 사진을 찍습니다. 촬영 후에 사용자는 기본 필터 또는 빈티지 필터를 고릅니다.

- 대상 플랫폼: iOS (개발 중에는 Android 에뮬레이터로도 확인합니다)
- 프레임워크: Flutter 3.44.8, Dart 3.12.2
- 상태: MVP 개발 중. Android 에뮬레이터에서 전체 흐름을 확인했습니다. iPhone에서는 아직 확인하지 않았습니다.

## 핵심 원칙

- MVP에는 로그인, SNS, AI를 넣지 않습니다.
- 핵심 기능은 2개입니다. 구도 가이드와 빈티지 필터입니다.
- 먼저 개발합니다. 그 다음 실제 기기에서 테스트합니다. 발견한 문제를 단계적으로 수정합니다.

## 사용 흐름

1. 사용자가 앱을 켭니다. 앱이 카메라 권한을 요청합니다.
2. 사용자가 사진의 비율을 고릅니다 (4:3 또는 16:9).
3. 사용자가 촬영 장면을 고릅니다. 앱이 그 장면의 첫 가이드를 표시합니다.
4. 사용자가 가이드를 고릅니다. 필요하면 가이드를 좌우로 뒤집습니다.
5. 사용자가 가이드에 맞춰 셔터 버튼을 누릅니다.
6. 앱이 결과 화면에 사진을 표시합니다.
7. 사용자가 필터를 고릅니다.
8. 사용자가 저장 버튼을 누릅니다. 앱이 원본과 필터 적용본을 사진 보관함에 저장합니다.

## 기능

### 구도 가이드

장면 5개에 가이드 14종이 있습니다. 가이드는 흰색 선으로 그립니다. 밝은 장면에서도 보이도록 선 아래에 반투명 검은 선을 그립니다.

| 장면 | 가이드 |
|---|---|
| 인물 | 삼분할, 황금 나선, 중앙, 여백 |
| 풍경 | 삼분할, 황금 분할, 대각선, S자, 여백 |
| 건축·도시 | 대칭, 프레임 속 프레임, 삼각형, 반복 |
| 음식·카페 | 중앙, 삼분할, 대각선, 삼각형 |
| 길·골목 | 소실점, 유도선, 대칭, V자 |

| 가이드 | 모양 | 좌우 반전 |
|---|---|---|
| 삼분할 | 가로선 2개, 세로선 2개 (1/3, 2/3 위치) | – |
| 황금 분할 | 가로선 2개, 세로선 2개 (0.382, 0.618 위치) | – |
| 황금 나선 | 황금 사각형을 반복해서 나눈 나선 | 가능 |
| 중앙 | 화면 중앙의 원 | – |
| 여백 | 화면 위쪽의 큰 빈 영역 | – |
| 대각선 | 왼쪽 위에서 오른쪽 아래로 가는 선 | 가능 |
| S자 | S자 곡선 | 가능 |
| 대칭 | 화면 중앙의 세로선 | – |
| 프레임 속 프레임 | 아치 모양 (윗변이 반원) | – |
| 삼각형 | 삼각형 | – |
| 반복 | 같은 크기의 사각형 3개 | – |
| 소실점 | 중앙의 작은 사각형과 꼭짓점을 잇는 선 4개 | – |
| 유도선 | 작은 원과, 원으로 모이는 선 6개 | – |
| V자 | V자 | – |

가이드는 4:3과 16:9에서 모두 맞게 그려집니다. 원과 아치는 두 비율에서 모두 원으로 보입니다.

가이드는 저장하는 사진에 포함하지 않습니다.

### 사진 비율

- 촬영 화면의 왼쪽 위 버튼으로 4:3과 16:9를 고릅니다.
- 화면은 세로로 고정합니다. 따라서 4:3 사진은 세로 3:4이고, 16:9 사진은 세로 9:16입니다.
- 앱은 미리보기와 저장 사진을 같은 비율로 가운데에서 자릅니다. 미리보기에서 본 영역이 그대로 저장됩니다.

### 필터

필터는 촬영 후 결과 화면에서 고릅니다. 필터는 2개 묶음입니다.

**기본 (5개)**: 색만 바꿉니다.

| 이름 | 효과 |
|---|---|
| 원본 | 필터 없음 |
| 선명하게 | 채도와 대비를 높입니다. |
| 따뜻하게 | 붉은 쪽으로 옮깁니다. |
| 차갑게 | 푸른 쪽으로 옮깁니다. |
| 흑백 | 흑백 |

**빈티지 (7개)**: 색을 바꾸고 필름 입자와 비네팅(가장자리 어둡게)을 더합니다.

| 이름 | 효과 |
|---|---|
| 따뜻한 필름 | 따뜻한 색, 약간 낮은 채도, 약간 바랜 검정 |
| 바랜 사진 | 낮은 채도, 낮은 대비, 바랜 검정 |
| 노을빛 | 강한 주황색, 약간 밝음 |
| 차가운 필름 | 청록색, 부드러운 대비 |
| 진한 슬라이드 | 높은 채도, 높은 대비 |
| 즉석 사진 | 밝음, 낮은 대비, 강한 비네팅 |
| 흑백 필름 | 흑백, 강한 입자 |

필터의 값은 임시 값입니다. 실제 iPhone에서 보면서 조정합니다. 필터 이름에는 등록 상표(Kodak, Polaroid 등)를 쓰지 않습니다.

### 저장

- 저장 버튼을 누르면 앱이 사진 2장을 사진 보관함에 저장합니다. iOS에서는 사진 앱이고, Android에서는 갤러리입니다.
  1. 원본: 고른 비율로 자른 사진. 필터가 없습니다.
  2. 필터 적용본
- "원본" 필터를 고르면 1장만 저장합니다.
- 원본을 먼저 저장합니다. 필터 적용본의 저장이 실패해도 원본은 남습니다.
- 파일 이름은 `mangcut_<시각>_original.jpg`와 `mangcut_<시각>_<필터 id>.jpg`입니다.
- 형식은 JPEG(품질 92)입니다. 긴 변은 최대 4032픽셀입니다.
- 별도 앨범은 만들지 않습니다.

### 그 밖의 기능

- 전면 카메라와 후면 카메라를 바꿉니다 (촬영 화면의 오른쪽 위 버튼).
- 전면 카메라로 찍은 사진은 미리보기와 같은 좌우로 저장합니다.
- 앱이 백그라운드로 가면 카메라를 닫습니다. 앱이 돌아오면 카메라를 다시 엽니다.
- 카메라 권한이 없으면 화면에 안내 문구를 표시합니다.

## 화면 구성

### 촬영 화면

| 위치 | 요소 |
|---|---|
| 미리보기 왼쪽 위 | 비율 버튼 (4:3, 16:9) |
| 미리보기 오른쪽 위 | 카메라 전환 버튼, 가이드 좌우 반전 버튼 (반전할 수 있는 가이드일 때만) |
| 미리보기 위 | 선택한 가이드 |
| 아래쪽 | 장면 탭, 가이드 목록 ("없음" 포함), 셔터 버튼 |

4:3에서는 미리보기와 조작부가 겹치지 않습니다. 16:9에서는 조작부가 미리보기의 아래쪽 위에 반투명하게 겹칩니다.

### 결과 화면

| 위치 | 요소 |
|---|---|
| 위쪽 | 촬영한 사진 (선택한 필터 적용) |
| 아래쪽 | 필터 묶음 탭 (기본, 빈티지), 필터 목록, 다시 찍기 버튼, 저장 버튼 |

## Mac에서 iPhone으로 실행하기

카메라는 iOS 시뮬레이터에서 동작하지 않습니다. 실제 iPhone을 쓰십시오.

### 준비

- Flutter 3.44 이상
- Xcode와 CocoaPods
- Apple ID (무료 계정으로도 내 iPhone에 설치할 수 있습니다)
- USB 케이블로 Mac에 연결한 iPhone. iPhone의 "개발자 모드"를 켭니다 (설정 → 개인정보 보호 및 보안 → 개발자 모드).

### 절차

1. 저장소를 받습니다.

   ```bash
   git clone https://github.com/Yun-sooyong/mangcut-bangji.git
   ```

2. 프로젝트 폴더로 이동해서 패키지를 받습니다.

   ```bash
   cd mangcut-bangji && flutter pub get
   ```

3. Xcode로 iOS 프로젝트를 엽니다.

   ```bash
   open ios/Runner.xcworkspace
   ```

4. Xcode에서 Runner → Signing & Capabilities를 엽니다. Team에 본인의 Apple ID를 지정합니다. Bundle Identifier가 다른 앱과 겹치면 바꿉니다 (기본값: `com.mangcut.mangcutBangji`).
5. 연결한 iPhone에서 앱을 실행합니다.

   ```bash
   flutter run --release
   ```

6. 처음 실행하면 iPhone이 개발자를 신뢰하지 않는다고 표시할 수 있습니다. 이때는 설정 → 일반 → VPN 및 기기 관리에서 개발자를 신뢰합니다.

### iPhone에서 확인할 항목

1. 첫 실행에서 카메라 권한을 허용하면 미리보기가 바로 나옵니다.
2. 저장한 사진이 똑바로 서 있습니다 (옆으로 눕지 않습니다).
3. 미리보기에서 본 영역과 저장한 사진의 영역이 같습니다 (4:3과 16:9 모두).
4. 전면 카메라로 찍은 사진의 좌우가 미리보기와 같습니다.
5. 저장에 걸리는 시간이 너무 길지 않습니다.
6. 빈티지 필터의 색감과 입자의 세기가 적당합니다.

## 기술 설계

### 가이드

- 가이드 1개는 도형(직선, 사각형, 타원, 경로)의 목록입니다.
- 좌표는 화면 크기에 대한 비율(0.0–1.0)입니다. 그리기 직전에 화면 크기를 곱합니다.
- 가이드는 화면 비율(너비 ÷ 높이)을 받아서 도형을 만듭니다. 원처럼 모양을 유지해야 하는 도형은 이 값으로 높이를 계산합니다.
- 이미지 파일을 쓰지 않습니다. 그래서 모든 비율에서 선이 선명하고 굵기가 일정합니다.

### 필터

- 필터 1개는 4×5 색 행렬, 입자의 강도, 비네팅의 강도로 구성됩니다.
- 색 행렬은 채도, 대비, 밝기, 채널 배율, 바램을 이어 붙여서 만듭니다.
- 화면 표시와 저장은 같은 값과 같은 그리기 함수(`paintFilterOverlays`)를 씁니다. 그래서 화면에서 본 색과 저장한 사진의 색이 같습니다.
- 색 행렬은 모든 색에 같은 계산을 합니다. "그림자만 초록색" 같은 톤별 색 변경은 못 합니다. 더 정교한 필터가 필요하면 셰이더(LUT)로 바꿉니다. 이때는 `PhotoFilter`와 `filter_renderer.dart`의 내부만 고칩니다.

### 미리보기와 저장 사진의 영역

- 카메라가 주는 영상의 비율은 기기마다 다릅니다.
- 앱은 미리보기와 촬영한 사진을 모두 고른 비율로 가운데에서 자릅니다.
- 한쪽 비율은 센서 영상의 일부를 버립니다. 그 비율의 해상도는 조금 낮아집니다.

### 저장

- 촬영한 JPEG를 디코딩합니다. 고른 비율로 자르고, 전면 카메라면 좌우를 뒤집습니다. 이 이미지가 원본입니다.
- 원본에 필터를 적용해서 필터 적용본을 만듭니다.
- JPEG 인코딩은 별도 isolate에서 실행합니다. 화면이 멈추지 않습니다.
- 다시 인코딩하므로 원본에는 EXIF(촬영 시간, 기종)가 남지 않습니다.

## 알려진 제한과 확인하지 않은 항목

- iPhone에서는 아직 실행하지 않았습니다. 위의 "iPhone에서 확인할 항목"을 확인해야 합니다.
- 전면 카메라의 좌우 반전은 실제 기기에서 확인하지 않았습니다.
- 고해상도 사진(12MP)의 저장 속도를 확인하지 않았습니다. 사진 2장을 인코딩하므로 수 초가 걸릴 수 있습니다.
- 필터의 값은 임시 값입니다. 실제 사진으로 조정해야 합니다.
- 저장한 사진에는 EXIF가 없습니다.
